# Archive

A change lands here when its work is delivered and verified, not when it stops being discussed.
Each directory keeps the change exactly as it was — proposal, design, specs, tasks and the log that
records what happened, including the decisions taken by delegation — plus one `archive-report.md`
that says what was done, why, how, and how it was proven.

Two rules that keep this honest:

- **The log is never rewritten.** A change archived here may still contain references to
  `openspec/changes/<name>/…`, because that is where the file lived when the sentence was written.
  Those pointers are historical, not broken links to follow.
- **The living specification is elsewhere.** `database/diagram_base.txt` is the model,
  `api/openapi.yaml` is the HTTP contract, `api/API.md` is the flows for a consumer, and
  `odd/tasks/*.md` holds the feature slices. A spec delta here that never landed is a decision,
  and the report says so.
